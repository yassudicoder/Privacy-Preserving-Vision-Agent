Ground Station - Live Downlink

Simulated vehicle telemetry, generated in this browser tab. New frames arrive continuously; nothing is fetched and nothing is sent.

SIMULATED DATA. Every reading is generated by mission.js in this page. The last four columns are invented test PII - a name, an address, a phone number and a station IP - present so the redaction layer has something to remove. The addresses and IP ranges are reserved by RFC and can never belong to anyone. No value here relates to a real person, mission or vehicle.
